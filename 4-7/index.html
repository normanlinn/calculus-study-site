Optimization Problems

Word problems: write one function of one variable, then use the max/min tools.

0 / 8 problems mastered

Your assigned problems are #3–7 odd (number problems) and #25–27 (geometry). They follow one recipe:

  1. Draw and name the variables.
  2. Write the quantity to optimize (the objective).
  3. Use the constraint to eliminate all but one variable.
  4. State the domain.
  5. Set the derivative to 0, then confirm max or min (first/second derivative test, or the endpoints).
  6. Answer the actual question, with units.
Objective vs constraint

The objective is what you maximize or minimize (area, cost, distance). The constraint is the fixed fact (sum is 100, fence is 2400 ft). Solve the constraint for one variable and substitute.

Distance trick

To minimise a distance, minimise d2d^2d2 instead. Same answer, no square root.

Justify it

Write one line such as “f′′>0f''>0f′′>0, so this is a min” or “f′f'f′ changes +→−+\to-+→−”. Teachers take marks off without it.

Answering the wrong question
