Memory trick

Every “co-” function (cos, cot, csc) gets a minus sign. tan ↔ sec² and cot ↔ csc² pair up; sec and csc reproduce themselves.

Proving the trig derivatives

Quizzes often ask you to show a formula, like ddxcot⁡x=−csc⁡2x\frac{d}{dx}\cot x=-\csc^2xdxd​cotx=−csc2x. Every one of these proofs uses the same four moves:

  1. Rewrite the function using only sin⁡\sinsin and cos⁡\coscos: cot⁡x=cos⁡xsin⁡x\cot x=\frac{\cos x}{\sin x}cotx=sinxcosx​, sec⁡x=1cos⁡x\sec x=\frac1{\cos x}secx=cosx1​, csc⁡x=1sin⁡x\csc x=\frac1{\sin x}cscx=sinx1​, tan⁡x=sin⁡xcos⁡x\tan x=\frac{\sin x}{\cos x}tanx=cosxsinx​.
  2. Quotient rule (low d-high minus high d-low, over low squared).
  3. Simplify the top with sin⁡2x+cos⁡2x=1\sin^2x+\cos^2x=1sin2x+cos2x=1.
  4. Rewrite back into the target form, splitting a fraction if needed: sin⁡xcos⁡2x=1cos⁡x⋅sin⁡xcos⁡x\frac{\sin x}{\cos^2x}=\frac1{\cos x}\cdot\frac{\sin x}{\cos x}cos2xsinx​=cosx1​⋅cosxsinx​.

Write it as a chain of equals signs starting from ddx(… )\frac{d}{dx}(\dots)dxd​(…) and ending at the formula. Never start from the answer and work backward.

Why sin θ / θ → 1

On a unit circle the arc has length θ and the pink segment has length sin θ. As θ shrinks, the arc straightens out and the two lengths become equal, so their ratio → 1.

Using the limit: make the denominator match the angle. Multiply and divide by what you need:

Traps

Degrees

All these formulas need radians. In degrees, (sin⁡x)′=π180cos⁡x(\sin x)'=\frac{\pi}{180}\cos x(sinx)′=180π​cosx.

sin 7x / 4x → 7/4, not 1

The limit is 1 only when the angle and the denominator are identical.

Missing minus signs

cos, cot, csc all give negatives. Say “co- means minus” as you write.
